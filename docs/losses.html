One optimization rule.
Different definitions of error.

Training chooses parameters θ to minimize an average loss. Fine-tuning uses task labels or feedback. Distillation uses a teacher’s outputs as supervision; it is a training setup, not one unique loss. Architecture controls which predictions the model can make efficiently.

L̂(θ) = (1/N) Σ_i ℓ(f_θ(x_i), target_i)
θ_new = θ − η ∇_θ L̂
∇_θ L = (∂L/∂model output) · (∂model output/∂θ)

A toy loss is not a benchmark. Lower training loss can coexist with worse retrieval, ranking, calibration or generation. Compare objectives with held-out task metrics, the same data split and realistic candidate sampling. Loss magnitudes from different objectives and reductions are not directly comparable.

Bi-encoders(q,d) = f(q) · g(d)

Encode independently; precompute document vectors. Optimize similarity geometry and candidate discrimination.

Cross-encoders(q,d) = h([q;d])

Jointly inspect query and document. Optimize relevance scores, pair preferences or ranked candidate lists.

Decoderπ(y|x) = Π_t π(y_t|x,y_<t)

Predict a sequence. Optimize token likelihood, teacher distributions, preferences or expected reward.

Decoder here means a language-generating decoder. A cross-encoder can itself use a decoder backbone; the columns below describe the application, not mutually exclusive transformer components.

    Keep these distinctions explicit in a training experiment
    • A loss, a mining strategy, a data-generation pipeline and a memory optimization are different interventions.
    • Record whether reductions average examples, pairs, dimensions or tokens; that changes gradient scale and weighting.
    • For distillation, specify teacher, student, target space, temperature, projection and which trajectories supply prefixes.
    • Fit normalization and thresholds on training/development data. Keep test labels out of mining and checkpoint selection.
    • Test teacher mistakes and hard negatives, not just a batch with an easy positive.
